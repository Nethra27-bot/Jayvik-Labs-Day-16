Day 16 – Wireshark Network Traffic Analysis

!Kali Linux !Tool !Domain !Status

Project Overview

This project focuses on understanding Wireshark, an open-source network protocol analyzer used to capture, inspect, and analyze network traffic.

The objective is to learn packet capture, network protocols, display filters, and basic network traffic analysis.

Student Name: Nethra M
Assignment: Day 16
Topic: Wireshark Network Traffic Analysis
Operating System: Kali Linux
Tool: Wireshark

Learning Objectives
Understand packet capture and network interfaces.
Identify source and destination IP addresses.
Learn Wireshark display filters.
Analyze DNS, ICMP, and TCP traffic.
Understand the TCP three-way handshake.
Learn about HTTPS encryption.
Understand PCAP and PCAPNG files.
Explore network traffic analysis in cybersecurity.
Important Wireshark Filters
Filter	Purpose
icmp	Displays ICMP traffic
dns	Displays DNS traffic
tcp	Displays TCP traffic
udp	Displays UDP traffic
http	Displays HTTP traffic
tls	Displays TLS traffic
tcp.port == 443	Displays TCP traffic involving port 443
Key Concepts
Wireshark: Network protocol analysis tool.
Packet Capture: Collecting network packets.
DNS: Converts domain names into IP addresses.
ICMP: Used for network diagnostics.
TCP Handshake: SYN, SYN-ACK, ACK.
HTTPS: Encrypted web communication using TLS.
PCAP/PCAPNG: Formats used to save packet captures.
Learning Outcomes

Through this assignment, I learned the fundamentals of packet analysis, network protocols, display filters, TCP communication, DNS resolution, and network troubleshooting.
